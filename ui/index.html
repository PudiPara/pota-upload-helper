          ロガーとの接続

          ロガーが記録した QSO を UDP で受け取ります。形式は N1MM（RUMlogNG・N1MM Logger+ など）、WSJT-X（WSJT-X・JTDX）、ADIF（JTAlert・GridTracker・Log4OM など）。届いたデータの形式はアプリが自動で判別します。

          同じ QSO が 2 つの受信口から届いたら

          WSJT-X の QSO は、WSJT-X から直接と、RUMlogNG が受けて送り直した分の 2 回届きます。同じコール・同じバンドで時刻の差が 3 分以内なら同じ交信として 1 件にまとめるので、両方オンにしても二重にはなりません。P2P の判断も削除も両方の控えに一緒に反映されます。逆に、同じ局と同じバンドで 3 分以内に 2 回交信した場合も 1 件になります。

          RUMlogNG の設定

          Preferences → UDP の「Contact info」を Contact info N1MM にして、Host を 127.0.0.1、Port をここの受信口と同じ番号にします。ほかのアプリ（OpsLog など）にも渡したいときは、この受信口の「転送先」にそのアプリの受信ポートを入れてください。

          WSJT-X / JTDX

          Settings → Reporting の UDP Server を 224.0.0.1（マルチキャスト）にすると、RUMlog や GridTracker と同時に受け取れます。
